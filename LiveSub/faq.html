Frequently Asked Questions (FAQ)

Q1: What is LiveSub?

A1: LiveSub is a real-time subtitle capture and translation application. It allows users to capture text from their screen and translate it instantly using OCR and AI-powered translation engines.

Q2: Which platforms does LiveSub support?

A2: LiveSub currently supports only the Windows platform in its latest versions.

Q3: How does the OCR work?

A3: LiveSub uses an advanced Optical Character Recognition engine that detects text in real-time on your screen, including videos, apps, and games. It is optimized for speed and high accuracy.

Q4: Which translation engines are available?

A4: Users can choose between the licensed LS Translate and DeepL. Both are capable of providing high-quality translations for nearly 20 languages.

Q5: Can I customize the subtitle appearance?

A5: Yes, the current version of LiveSub offers you some options for customizing your subtitles.

Q6: Is LiveSub privacy-friendly?

A6: Yes, LiveSub prioritizes privacy. Most processing happens locally on your machine, and any temporary data is securely deleted. No personal data is stored permanently without consent.

Q7: Can I use LiveSub on multiple monitors?

A7: LiveSub supports multiple screens, capturing and translating text across all connected displays simultaneously.

Q8: What are the system requirements?

A8: Minimum: 4GB RAM, 2 GHz CPU, 500 MB free disk space. Recommended: 8GB RAM, 4+ GHz CPU, SSD preferred for optimal performance.

Q9: How often is LiveSub updated?

A9: We provide frequent updates to improve OCR accuracy, translation performance, add new languages, and integrate user feedback.

Q10: How do I get support?

A10: Our support team is available via the contact page or email at mr.ensartosun@hotmail.com. We also provide extensive documentation and tutorials on our website.

Q11: Is there a mobile version of LiveSub?

A11: Currently, LiveSub is designed for desktop platforms. Mobile support is being explored for future updates.

Q12: Can LiveSub be used for educational purposes?

A12: Absolutely! LiveSub is ideal for students, online courses, and webinars. It helps capture and translate subtitles for better understanding.

Q13: Are there accessibility options?

A13: Yes, LiveSub supports screen readers, keyboard navigation, and high-contrast modes to make it accessible for all users.

Q14: Can I customize the translation engine settings?

A14: Power users can adjust OCR sensitivity, translation latency, and caching settings for optimized performance.
